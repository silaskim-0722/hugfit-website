# 허그핏스타점핑 웹사이트

군산 나은동 No.1 다이어트 트램폴린 센터 허그핏스타점핑의 공식 웹사이트입니다.

## 🎯 프로젝트 개요

허그핏스타점핑은 트램폴린을 이용한 재미있고 효과적인 다이어트 프로그램을 제공하는 피트니스 센터입니다. 2026년 신년을 맞아 새로운 모습으로 단장한 웹사이트로 고객들에게 프로그램 소개, 회원권 안내, 칼로리 계산기 등의 다양한 서비스를 제공합니다.

## ✨ 주요 기능

### 현재 구현된 기능

1. **네비게이션 바**
   - 고정 헤더 (스크롤 시 배경 효과)
   - 메뉴: 스토어, 공지, 갤러리, 후기게시판
   - 네온 그린 CONTACT 버튼

2. **히어로 섹션**
   - 실제 트램폴린 운동 배경 이미지
   - "HAPPY NEW YEAR 2026" 테마
   - 다크 오버레이와 네온 그린 하이라이트
   - 2개의 CTA 버튼 (빠른 상담예약, 일정 체험 문의)

3. **WHY 점핑? 섹션**
   - 3가지 핵심 강점 소개
   - 단 45분의 기적 (볼트 아이콘)
   - 관절 무리 NO (실드 아이콘)
   - 스트레스 타파 (스마일 아이콘)
   - 각각 다른 네온 색상 (그린, 시안, 핑크)

4. **회원권 안내**
   - 3가지 기본 회원권 플랜
     - 횟권 (주2회/월10회): 90,000원
     - 월권 (1개월 프리패스): 160,000원 ⭐ 베스트
     - 주로 30회권: 250,000원
   - 특별 프로그램: 1:1 개인성 프로그램 (580,000원)
   - 기타 옵션 및 1회 체험권 (10,000원)
   - 각 카드별 네온 그린/시안 라인 강조

5. **칼로리 계산기**
   - 실시간 칼로리 소모량 계산
   - 입력: 몸무게(kg), 운동 시간(30/45/60분)
   - 출력: 예상 소모 칼로리, 조깅 환산 거리
   - 한 달 지속 시 예상 감량 표시
   - 네온 그린 버튼과 결과 카드

6. **오시는 길**
   - 네이버 지도 연동
   - 주소: 군산 나운5길 16 2층 허그핏스타점핑
   - 연락처: 0507-1420-0735
   - 운영시간: 평일 09:30 - 21:30 (주말 사전 별도 문의)
   - 3가지 정보 카드 (주소, 연락처, 운영시간)

7. **갤러리 섹션**
   - HAPPY STAR JUMPERS
   - 4개의 그라데이션 플레이스홀더
   - 호버 시 확대 효과

8. **푸터**
   - 센터 소개
   - 연락처 및 주소 정보
   - 저작권 표시

## 🚀 주요 기능 상세

### 1. 칼로리 계산기
**입력값**:
- 현재 몸무게 (kg)
- 운동 시간 (30/45/60분)

**계산 공식**:
```javascript
// 트램폴린 운동: 시간당 체중 × 12 kcal
calories = (weight × 12 × duration) / 60

// 조깅 환산: 시속 8km, 약 50 kcal/km
distance = calories / 50

// 한 달 감량: 1kg 지방 = 7700 kcal
fatLoss = (calories × 20) / 7700
```

**출력값**:
- 예상 소모 칼로리 (kcal)
- 조깅 환산 거리 (km)
- 한 달 지속 시 예상 감량 (kg)

### 2. 네이버 지도 연동
- 네이버 지도 iframe 사용
- 실제 센터 위치 표시
- 주소: 군산 나운5길 16 2층

### 3. 인터랙티브 효과
- **스크롤 애니메이션**: Intersection Observer 활용
- **패럴랙스 효과**: 히어로 배경 이미지 움직임
- **호버 효과**: 카드, 버튼, 갤러리 아이템
- **부드러운 스크롤**: 네비게이션 클릭 시
